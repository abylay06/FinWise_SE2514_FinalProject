# FinWise

We built FinWise for our Web Technologies final project using HTML, CSS and JavaScript. Visitors can convert currencies, plan a savings goal, explore financial services and leave a review. The currency converter uses ExchangeRate-API, and the stock charts on the Markets page come from TradingView.

Amir K. worked on About and Testimonials. Abylay A. worked on Home and Services. We built Markets, Account and Profile together and worked on the shared JavaScript.
